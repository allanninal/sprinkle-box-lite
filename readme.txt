== Description ==

A playful block theme for donut shops, bakeries and dessert counters. Patterns for today's batch, the full menu, a menu board, build-your-dozen boxes, your story, a photo gallery, and opening hours with a live open-now line, all editable in the Site Editor.

Sprinkle Box Lite is a block theme: every page, header and footer is edited in the Site Editor, with no page builder. The front page is built from patterns you can rearrange, and each section is also in the pattern inserter for any page.

A contact form is plugin territory: for a form on your contact page, install a form plugin from WordPress.org.

The full version of Sprinkle Box adds a one-click demo import (pages, menu, photos and journal posts), a WooCommerce shop set up with products and photos, a dark style and a setup guide: https://checkout.freemius.com/theme/42973/plan/74805/

== Frequently Asked Questions ==

= Does the theme collect any data? =

No. Sprinkle Box Lite sets no cookies and uses no tracking. To offer updates it asks GitHub (api.github.com) for the latest release of github.com/allanninal/sprinkle-box-lite, at most twice a day; that request carries nothing about your site. The upgrade notice in the dashboard is a plain link; dismissing it is stored on your own site.

= How do I update it? =

Like any theme: new versions appear under Dashboard › Updates. Each version is also a release at https://github.com/allanninal/sprinkle-box-lite/releases, with the theme zip attached. Install that zip, not GitHub's "Source code" download, whose folder name is different.
